# Halaman Home untuk John Doe
## Deskripsi
Halaman home ini dirancang untuk menyambut John Doe setelah login, dengan tampilan yang menarik dan responsif. Halaman ini menampilkan informasi tentang produk terbaru, penawaran khusus, dan dashboard pengguna.

## Desain
Halaman home ini memiliki desain yang modern dan minimalis, dengan warna utama biru dan putih. Header halaman menampilkan logo Agentic AI Employee Platform dan nama pengguna John Doe. Navigation bar memiliki tiga menu utama: Dashboard, Produk, dan Penawaran.

## Struktur Halaman
Halaman home ini memiliki struktur sebagai berikut:
```markdown
- Header
  - Logo Agentic AI Employee Platform
  - Nama Pengguna (John Doe)
  - Navigation Bar
    - Dashboard
    - Produk
    - Penawaran
- Section 1: Produk Terbaru
  - Judul: Produk Terbaru
  - Deskripsi: Informasi tentang produk terbaru
  - Tombol: Lihat Detail
- Section 2: Penawaran Khusus
  - Judul: Penawaran Khusus
  - Deskripsi: Informasi tentang penawaran khusus
  - Tombol: Lihat Detail
- Section 3: Dashboard Pengguna
  - Judul: Dashboard Pengguna
  - Informasi: Informasi tentang pengguna, termasuk jumlah produk yang dibeli dan penawaran yang digunakan
  - Tombol: Lihat Detail
- Footer
  - Informasi Kontak
  - Link ke Halaman lain
```

## Contoh Code
Berikut adalah contoh code untuk halaman home menggunakan Next.js dan TailwindCSS:
```jsx
import Head from 'next/head';
import Header from '../components/Header';
import Footer from '../components/Footer';
import Section1 from '../components/Section1';
import Section2 from '../components/Section2';
import Section3 from '../components/Section3';

function Home() {
  return (
    <div>
      <Head>
        <title>Agentic AI Employee Platform</title>
      </Head>
      <Header />
      <Section1 />
      <Section2 />
      <Section3 />
      <Footer />
    </div>
  );
}

export default Home;
```
