#### Warna dan Spasi
* Latar belakang: `bg-background` (`#0F172A`)
* Warna teks judul: `text-text` (`#F8FAFC`)
* Warna teks subjudul: `text-secondary` (`#94A3B8`)
* Warna tombol: `bg-accent` (`#F59E0B`)
* Spasi antar elemen: `mt-4`, `mt-8`

#### Gradient Hero
* Gradient: `bg-gradient-to-b from-primary to-secondary` (`#6366F1` ke `#8B5CF6`)

#### Tailwind Classes
* `h-screen`: tinggi layar penuh
* `flex`: layout flexbox
* `justify-center`: rata tengah horizontal
* `items-center`: rata tengah vertikal
* `bg-gradient-to-b`: gradient dari atas ke bawah
* `from-primary`: warna awal gradient (#6366F1)
* `to-secondary`: warna akhir gradient (#8B5CF6)
* `text-text`: warna teks (#F8FAFC)
* `text-secondary`: warna teks subjudul (#94A3B8)
* `bg-accent`: warna tombol (#F59E0B)
* `rounded-md`: sudut tombol
* `hover:bg-opacity-80`: efek hover pada tombol
* `mt-4`, `mt-8`: spasi antar elemen
