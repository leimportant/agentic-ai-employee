Berikut adalah contoh `docker-compose.yml` untuk produksi dan konfigurasi Nginx reverse proxy:

**docker-compose.yml (produksi)**
```yml
version: '3'

services:
  backend:
    build: ./backend
    environment:
      - DATABASE_URL=postgres://user:password@db:5432/database
      - REDIS_URL=redis://redis:6379/0
    ports:
      - "8000:8000"
    depends_on:
      - db
      - redis
    restart: always

  frontend:
    build: ./frontend
    environment:
      - NEXT_PUBLIC_API_URL=https://api.domain.com
    ports:
      - "3000:3000"
    depends_on:
      - backend
    restart: always

  db:
    image: postgres:15
    environment:
      - POSTGRES_USER=user
      - POSTGRES_PASSWORD=password
      - POSTGRES_DB=database
    volumes:
      - db-data:/var/lib/postgresql/data
    restart: always

  redis:
    image: redis:alpine
    restart: always

  minio:
    image: minio/minio:latest
    environment:
      - MINIO_ACCESS_KEY=minio-access-key
      - MINIO_SECRET_KEY=minio-secret-key
    volumes:
      - minio-data:/data
    restart: always

volumes:
  db-data:
  minio-data:
```

**Nginx konfigurasi (default.conf)**
```bash
server {
    listen 80;
    server_name app.domain.com;

    location / {
        proxy_pass http://frontend:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}

server {
    listen 80;
    server_name api.domain.com;

    location / {
        proxy_pass http://backend:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}

server {
    listen 443 ssl;
    server_name app.domain.com;

    ssl_certificate /etc/letsencrypt/live/app.domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/app.domain.com/privkey.pem;

    location / {
        proxy_pass http://frontend:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}

server {
    listen 443 ssl;
    server_name api.domain.com;

    ssl_certificate /etc/letsencrypt/live/api.domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.domain.com/privkey.pem;

    location / {
        proxy_pass http://backend:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

**Penjelasan:**

* `docker-compose.yml` mendefinisikan layanan-layanan yang digunakan dalam aplikasi, termasuk backend, frontend, database, redis, dan minio.
* Nginx konfigurasi (`default.conf`) mendefinisikan konfigurasi reverse proxy untuk frontend dan backend, serta konfigurasi SSL untuk domain `app.domain.com` dan `api.domain.com`.
* Nginx mendengarkan port 80 dan 443, dan memproxy request ke layanan-layanan yang sesuai.
* Konfigurasi SSL menggunakan sertifikat Let's Encrypt.

**Perintah untuk menjalankan aplikasi:**

1. Buat folder `deploy` dan salin `docker-compose.yml` ke dalamnya.
2. Buat folder `nginx` dan salin `default.conf` ke dalamnya.
3. Jalankan perintah `docker-compose up -d` untuk menjalankan aplikasi dalam mode detached.
4. Jalankan perintah `nginx -t` untuk memeriksa konfigurasi Nginx.
5. Jalankan perintah `nginx` untuk menjalankan Nginx.

**Catatan:**

* Pastikan Anda telah menginstal Docker dan Nginx sebelum menjalankan aplikasi.
* Pastikan Anda telah mengkonfigurasi domain `app.domain.com` dan `api.domain.com` untuk menunjuk ke alamat IP server Anda.
* Pastikan Anda telah menginstal sertifikat Let's Encrypt untuk domain `app.domain.com` dan `api.domain.com`.
