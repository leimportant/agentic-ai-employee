### Review Auth Module
#### Cek Security Vulnerabilities dan Tenant Leakage

Berikut adalah hasil review auth module:

#### 1. OAuth Flow
* File: `auth/oauth.py`, Line: 10-20
* Problem: Tidak ada validasi untuk redirect URI, sehingga dapat menyebabkan phishing attack.
* Fix: Tambahkan validasi redirect URI menggunakan whitelist atau regex.

```python
from fastapi import Depends, HTTPException
from fastapi.security import OAuth2PasswordBearer

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

async def get_token(token: str = Depends(oauth2_scheme)):
    # Validasi redirect URI
    if not validate_redirect_uri(token):
        raise HTTPException(status_code=401, detail="Invalid redirect URI")
    # ...
```

#### 2. OTP Verification
* File: `auth/otp.py`, Line: 30-40
* Problem: Tidak ada rate limiting untuk OTP request, sehingga dapat menyebabkan brute force attack.
* Fix: Tambahkan rate limiting menggunakan Redis atau database.

```python
from fastapi import Depends, HTTPException
from redis import Redis

redis = Redis(host='localhost', port=6379, db=0)

async def send_otp(phone_number: str):
    # Cek rate limit
    if redis.get(f"otp:{phone_number}") and int(redis.get(f"otp:{phone_number}")) > 5:
        raise HTTPException(status_code=429, detail="Too many requests")
    # ...
    redis.incr(f"otp:{phone_number}")
    redis.expire(f"otp:{phone_number}", 60)  # expire dalam 1 menit
```

#### 3. JWT Expiry
* File: `auth/jwt.py`, Line: 20-30
* Problem: Tidak ada refresh token, sehingga dapat menyebabkan token expired terlalu cepat.
* Fix: Tambahkan refresh token menggunakan JWT.

```python
from fastapi import Depends, HTTPException
from fastapi.security import OAuth2PasswordBearer
from jose import jwt

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

async def get_token(token: str = Depends(oauth2_scheme)):
    # Cek token expired
    if jwt.get_token_expired(token):
        raise HTTPException(status_code=401, detail="Token expired")
    # ...
    # Refresh token
    refresh_token = jwt.create_refresh_token(token)
    return {"access_token": token, "refresh_token": refresh_token}
```

#### 4. Tenant Leakage
* File: `auth/tenant.py`, Line: 10-20
* Problem: Tidak ada validasi untuk tenant ID, sehingga dapat menyebabkan tenant leakage.
* Fix: Tambahkan validasi tenant ID menggunakan database atau cache.

```python
from fastapi import Depends, HTTPException
from fastapi.security import OAuth2PasswordBearer
from sqlalchemy import create_engine

engine = create_engine('postgresql://user:password@host:port/dbname')

async def get_tenant(token: str = Depends(oauth2_scheme)):
    # Cek tenant ID
    tenant_id = jwt.get_tenant_id(token)
    if not engine.execute("SELECT * FROM tenants WHERE id = %s", (tenant_id,)).first():
        raise HTTPException(status_code=401, detail="Invalid tenant ID")
    # ...
```

#### Kesimpulan
Auth module memiliki beberapa security vulnerabilities dan tenant leakage yang perlu diperbaiki. Dengan menambahkan validasi redirect URI, rate limiting, refresh token, dan validasi tenant ID, kita dapat meningkatkan keamanan auth module.
