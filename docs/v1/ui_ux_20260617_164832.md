### Dashboard Layout
#### Struktur Umum
Dasbor akan memiliki struktur umum sebagai berikut:
- **Sidebar**: Berada di sebelah kiri, berisi navigasi utama dan pengaturan akun.
- **Konten Utama**: Berada di sebelah kanan sidebar, berisi kartu-kartu informasi, tabel, dan fitur lainnya.

#### Sidebar
- **Latar Belakang**: `bg-slate-900` (#0F172A)
- **Warna Teks**: `text-white` (#F8FAFC)
- **Border Radius**: `rounded-6px` (6px)
- **Padding**: `p-4` (16px)
- **Lebar**: `w-64` (256px)

#### Konten Utama
- **Latar Belakang**: `bg-slate-800` (#1E293B)
- **Padding**: `p-8` (32px)

#### Kartu Informasi
- **Latar Belakang**: `bg-slate-800` (#1E293B)
- **Warna Teks**: `text-white` (#F8FAFC)
- **Border Radius**: `rounded-8px` (8px)
- **Padding**: `p-4` (16px)
- **Glow Efek**: `shadow-md` dengan warna `#6366F1` (Indigo) untuk memberikan efek glow

#### Tabel
- **Latar Belakang**: `bg-slate-800` (#1E293B)
- **Warna Teks**: `text-white` (#F8FAFC)
- **Border Radius**: `rounded-8px` (8px)
- **Padding**: `p-4` (16px)
- **Hover Efek**: `hover:bg-slate-700` (#334155) untuk memberikan efek hover

#### Chat Bubbles (WA-like)
- **Latar Belakang**: `bg-slate-800` (#1E293B)
- **Warna Teks**: `text-white` (#F8FAFC)
- **Border Radius**: `rounded-8px` (8px)
- **Padding**: `p-2` (8px)

### Contoh Code Tailwind
```markdown
<!-- Sidebar -->
<div class="bg-slate-900 text-white rounded-6px p-4 w-64">
  <!-- Navigasi dan Pengaturan Akun -->
</div>

<!-- Konten Utama -->
<div class="bg-slate-800 p-8">
  <!-- Kartu Informasi -->
  <div class="bg-slate-800 text-white rounded-8px p-4 shadow-md">
    <!-- Informasi -->
  </div>
  
  <!-- Tabel -->
  <div class="bg-slate-800 text-white rounded-8px p-4">
    <table>
      <!-- Kolom dan Baris Tabel -->
    </table>
  </div>
  
  <!-- Chat Bubbles -->
  <div class="bg-slate-800 text-white rounded-8px p-2">
    <!-- Chat -->
  </div>
</div>
```
### Spesifikasi Komponen
- **Font**: Inter untuk teks biasa, JetBrains Mono untuk kode.
- **Spacing**: Menggunakan spasi yang konsisten (4/8/12/16/24/32/48/64).
- **Responsive Breakpoints**: Menggunakan breakpoint default Tailwind (sm, md, lg, xl, 2xl).
- **Aksesibilitas**: Mengikuti standar WCAG 2.1 AA.
- **Micro-interactions**: Menggunakan efek hover, glow, dan transisi untuk memberikan pengalaman pengguna yang lebih baik.
