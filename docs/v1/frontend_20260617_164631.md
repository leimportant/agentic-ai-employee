Berikut adalah contoh kode untuk halaman dashboard admin dengan sidebar layout responsive menggunakan Next.js, TypeScript, dan shadcn/ui:
```tsx
import { useState } from 'react';
import {
  Sidebar,
  SidebarItem,
  SidebarCollapseButton,
  TopNavbar,
  Breadcrumb,
  SearchInput,
  NotificationBell,
  UserAvatarDropdown,
  ContentArea,
} from 'shadcn/ui';
import { Lucide } from 'lucide-react-native';
import { useZustandState } from 'zustand';

const DashboardPage = () => {
  const [sidebarOpen, setSidebarOpen] = useState(false);
  const { user } = useZustandState((state) => state);

  const handleSidebarToggle = () => {
    setSidebarOpen(!sidebarOpen);
  };

  return (
    <div className="flex h-screen flex-col">
      <TopNavbar>
        <Breadcrumb>
          <Breadcrumb.Item href="#">Dashboard</Breadcrumb.Item>
        </Breadcrumb>
        <SearchInput placeholder="Cari..." />
        <NotificationBell />
        <UserAvatarDropdown user={user} />
      </TopNavbar>
      <div className="flex-1 flex flex-row">
        <Sidebar
          className={`w-64 bg-slate-800 ${sidebarOpen ? 'block' : 'hidden md:block'}`}
          collapsible
        >
          <SidebarItem href="#" icon={<Lucide.Home />} active>
            Dashboard
          </SidebarItem>
          <SidebarItem href="#" icon={<Lucide.Robot />} >
            AI Agents
          </SidebarItem>
          <SidebarItem href="#" icon={<Lucide.User />} >
            Customers
          </SidebarItem>
          <SidebarItem href="#" icon={<Lucide.Settings />} >
            Settings
          </SidebarItem>
          <SidebarCollapseButton onClick={handleSidebarToggle} />
        </Sidebar>
        <ContentArea className="p-6 max-w-7xl">
          {/* Konten dashboard */}
          <h1 className="text-2xl font-bold">Dashboard</h1>
          <p>Selamat datang di dashboard admin!</p>
        </ContentArea>
      </div>
    </div>
  );
};

export default DashboardPage;
```
Pada kode di atas, kita menggunakan `useState` untuk mengelola status sidebar, dan `useZustandState` untuk mengambil data user dari store Zustand.

Kita juga menggunakan komponen `Sidebar`, `TopNavbar`, `Breadcrumb`, `SearchInput`, `NotificationBell`, dan `UserAvatarDropdown` dari shadcn/ui untuk membangun layout dashboard.

Pada bagian sidebar, kita menggunakan komponen `SidebarItem` untuk membuat item menu, dan `SidebarCollapseButton` untuk membuat tombol collapse sidebar.

Pada bagian content area, kita dapat menambahkan konten dashboard sesuai kebutuhan.

Untuk membuat layout responsive, kita menggunakan utility class dari Tailwind CSS, seperti `w-64` untuk lebar sidebar, dan `md:block` untuk membuat sidebar tersembunyi pada ukuran layar mobile.
