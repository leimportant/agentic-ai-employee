Berikut adalah contoh konfigurasi GitHub Actions untuk melakukan test, build, dan deploy ke VPS:

**.github/workflows/deploy.yml**
```yml
name: Deploy ke VPS

on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v2

      - name: Install dependencies
        run: |
          pip install -r requirements.txt
          npm install

      - name: Test backend
        run: |
          cd backend
          pytest

      - name: Test frontend
        run: |
          cd frontend
          npm run test

      - name: Build backend
        run: |
          cd backend
          docker build -t agentic-ai-backend .

      - name: Build frontend
        run: |
          cd frontend
          npm run build
          docker build -t agentic-ai-frontend .

      - name: Deploy ke VPS
        uses: appleboy/ssh-action@master
        with:
          host: ${{ secrets.VPS_HOST }}
          username: ${{ secrets.VPS_USERNAME }}
          password: ${{ secrets.VPS_PASSWORD }}
          script: |
            cd /home/ubuntu/deploy
            git pull
            docker-compose down
            docker-compose up -d
            docker exec -it agentic-ai-backend bash -c "python manage.py migrate"
            docker exec -it agentic-ai-backend bash -c "python manage.py collectstatic"
```
Penjelasan:

* `on.push.branches` menentukan bahwa workflow ini akan dijalankan ketika kode di branch `main` di-push ke repository.
* `jobs.deploy` menentukan bahwa workflow ini memiliki satu job yang bernama `deploy`.
* `steps` menentukan langkah-langkah yang akan dijalankan dalam job `deploy`.
* `Checkout code` menggunakan action `actions/checkout@v2` untuk mengunduh kode dari repository.
* `Install dependencies` menginstal dependencies yang diperlukan untuk menjalankan kode.
* `Test backend` menjalankan test untuk backend menggunakan pytest.
* `Test frontend` menjalankan test untuk frontend menggunakan npm run test.
* `Build backend` membangun image Docker untuk backend.
* `Build frontend` membangun image Docker untuk frontend.
* `Deploy ke VPS` menggunakan action `appleboy/ssh-action@master` untuk mengakses VPS menggunakan SSH. Kemudian, script dijalankan untuk:
	+ Mengunduh kode terbaru dari repository.
	+ Menghentikan container yang sedang berjalan.
	+ Menjalankan container baru menggunakan `docker-compose up -d`.
	+ Mengjalankan migrate dan collectstatic untuk backend.

**Simpan secrets**

Pastikan untuk menyimpan secrets berikut di repository:

* `VPS_HOST`: alamat IP VPS
* `VPS_USERNAME`: username untuk mengakses VPS
* `VPS_PASSWORD`: password untuk mengakses VPS

Cara menyimpan secrets:

1. Buka repository di GitHub.
2. Klik tombol "Settings" di bagian atas halaman.
3. Klik "Actions" di menu sebelah kiri.
4. Klik "Secrets" di menu sebelah kiri.
5. Klik tombol "New secret".
6. Masukkan nama secret dan nilai secret.
7. Klik tombol "Add secret".

Dengan demikian, workflow GitHub Actions akan dijalankan secara otomatis ketika kode di-push ke branch `main`.
