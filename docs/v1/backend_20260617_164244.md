from fastapi import APIRouter, Depends, HTTPException
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm
from pydantic import ValidationError
from sqlalchemy.orm import Session

from . import schemas, service
from ..database import get_db

router = APIRouter()

@router.post("/register")
async def register(user: schemas.UserRegister, db: Session = Depends(get_db)):
    db_user = service.create_user(db, user)
    return {"success": True, "data": db_user, "message": "Register berhasil"}

@router.post("/login")
async def login(form_data: OAuth2PasswordRequestForm = Depends(), db: Session = Depends(get_db)):
    user = service.authenticate_user(db, form_data.username, form_data.password)
    if not user:
        raise HTTPException(status_code=401, detail="Invalid username or password")
    token = service.create_jwt_token(user)
    return {"success": True, "data": token, "message": "Login berhasil"}

@router.post("/google-oauth")
async def google_oauth(code: str, db: Session = Depends(get_db)):
    user = service.google_oauth(db, code)
    token = service.create_jwt_token(user)
    return {"success": True, "data": token, "message": "Google OAuth berhasil"}

@router.post("/otp")
async def otp(otp_request: schemas.OTPRequest, db: Session = Depends(get_db)):
    user = service.verify_otp(db, otp_request.email, otp_request.otp)
    if not user:
        raise HTTPException(status_code=401, detail="Invalid OTP")
    token = service.create_jwt_token(user)
    return {"success": True, "data": token, "message": "OTP verifikasi berhasil"}

**Penjelasan**

*   Modul auth terdiri dari beberapa komponen, yaitu: `schemas.py`, `models.py`, `service.py`, dan `router.py`.
*   `schemas.py` berisi definisi schema untuk request dan response API auth.
*   `models.py` berisi definisi model untuk tabel users di database.
*   `service.py` berisi fungsi-fungsi yang digunakan untuk auth, seperti create user, authenticate user, google oauth, dan verify otp.
*   `router.py` berisi definisi route untuk API auth, seperti register, login, google oauth, dan otp verifikasi.

**Implementasi**

*   Untuk implementasi, Anda perlu mengimport modul auth di `main.py` dan menambahkan route auth ke aplikasi FastAPI.
*   Anda juga perlu mengkonfigurasi database dan implementasi google oauth, otp, dan jwt.
*   Pastikan Anda telah menginstal semua library yang diperlukan, seperti `fastapi`, `sqlalchemy`, `pydantic`, dan `python-jose`.

**Contoh Penggunaan**

*   Untuk register, Anda dapat mengirim request POST ke `/api/v1/auth/register` dengan body `{"nama": "John Doe", "email": "john@example.com", "password": "password123"}`.
*   Untuk login, Anda dapat mengirim request POST ke `/api/v1/auth/login` dengan body `{"username": "john@example.com", "password": "password123"}`.
*   Untuk google oauth, Anda dapat mengirim request POST ke `/api/v1/auth/google-oauth` dengan body `{"code": "code_dari_google"}`.
*   Untuk otp verifikasi, Anda dapat mengirim request POST ke `/api/v1/auth/otp` dengan body `{"email": "john@example.com", "otp": "otp_dari_telegram"}`.
