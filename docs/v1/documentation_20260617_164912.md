# Auth Module API Documentation
## Overview
Modul auth menyediakan fungsi autentikasi dan autorisasi untuk pengguna UMKM. Dokumentasi ini menjelaskan endpoint, request, dan response yang tersedia untuk modul auth.

## Endpoints
Berikut adalah endpoint yang tersedia untuk modul auth:

| Endpoint | Method | Deskripsi |
| --- | --- | --- |
| `/auth/login` | `POST` | Autentikasi pengguna |
| `/auth/register` | `POST` | Mendaftar pengguna baru |
| `/auth/forget-password` | `POST` | Mengirimkan email reset password |
| `/auth/reset-password` | `PATCH` | Mengubah password |
| `/auth/me` | `GET` | Mengambil informasi pengguna terkini |
| `/auth/logout` | `POST` | Mengeluarkan pengguna dari sistem |

```json
POST /auth/login HTTP/1.1
Content-Type: application/json

{
  "email": "example@example.com",
  "password": "password123"
}
```

### Register
#### Request
```json
POST /auth/register HTTP/1.1
Content-Type: application/json

{
  "name": "John Doe",
  "email": "example@example.com",
  "password": "password123"
}
```
#### Response
```json
HTTP/1.1 201 Created
Content-Type: application/json

{
  "user": {
    "id": 2,
    "name": "John Doe",
    "email": "example@example.com"
  }
}
```

```bash

# Register
curl -X POST -H "Content-Type: application/json" -d '{"name": "John Doe", "email": "example@example.com", "password": "password123"}' http://localhost:3000/auth/register

# Forget Password
```
